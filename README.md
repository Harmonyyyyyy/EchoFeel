# EchoFeel

EchoFeel is a creative social communication concept where people share short emotional messages paired with music. Every post is anonymous by default and transforms over time, encouraging reflection and emotional resonance instead of likes or follower counts.

## Prototype included in this repository

This repository currently contains a lightweight static prototype that demonstrates:

- a landing page describing the product vision,
- an anonymous composer for creating emotional music-linked posts, and
- an evolving feed where each post changes phase over time.

## Run locally

Because the project is static, you can open `index.html` directly in a browser or serve the repository with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
